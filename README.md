# 维斯佩拉 · Vespera

半生存、半 RPG 的 Minecraft 服务器（Paper 26.3 / Java 25）的工程骨架。
剧本、插件、地图资源放在同一个仓库里，用同一套 Maven 管；一条命令从空目录走到能进去说话的服务器。

> 这不是一个官方 Minecraft 产品。未经 Mojang、Microsoft 或网易（中国大陆的 Minecraft 独家运营方）批准或关联。
> 本仓库不含任何 Minecraft 游戏文件、服务端核心、贴图、音效、语言文件或字体。

## 现在是什么状态

| 部分 | 状态 | 说明 |
|---|---|---|
| 构建 | 可跑 | `mvn package` 出四个模块，插件 jar 直接落进 `server/plugins/` |
| 一键起服 | 可跑 | `./dev.sh` 自动下载 Paper 26.3、写配置、装插件、起服 |
| 冒烟验证 | 可跑 | `./dev.sh smoke` 起服 → 敲 `/vespera doctor` → 把每个对话节点都构造一遍 → 判退出码 |
| 对话 | 可用 | 两种渲染器共用一张剧本：原生 Dialog（挡路、能输入）与聊天栏可点击（不挡路） |
| 区域与地图 | 可用 | `regions/regions.yml` 是坐标唯一真相；插件按它判定区域，并把主城的下界门定向到熔炉之喉 |
| 内容闸门 | 可用 | `content.yml` 三道闸全关；图级 + 选项级；关着的线在客户端不存在 |
| 校历时钟 | 可用 | 六段作息 + 晚钟，阈值与种族插件严格对齐 |
| NPC 锚点 | 可用 | 原版村民 + 持久化身份，零依赖；Citizens 可选升级 |
| 地图资源 | 骨架 | 布置清单（`layouts/college.yml`）+ LFS 约定，`.schem` 待美术产出 |
| 剧情主线 | 未开始 | 42 章主线 + 72 章种族线，见 `docs/04-台本功能映射.md` |

## 快速开始

```bash
# 需要 JDK 25 与 Maven 3.9+
./dev.sh            # 起开发服（第一次会下 Paper，约 50 MB）
./dev.sh smoke      # 起、验、退；退出码 0 表示插件真的加载并答了话
./dev.sh debug      # 起服并挂上 JDWP 5005，插件可以打断点
```

进服之后：

```
/vespera doctor                     # 自检：版本、软依赖、剧本、区域、安全闸、时钟、锚点
/vespera where                      # 我在哪一块地方（建造时最常用）
/vespera talk bell-test             # 走一遍钟感测试（Dialog 界面）
/vespera talk patrol                # 巡夜人的一句话（聊天栏可点击）
```

出生点旁边站着一个叫「老修士」的村民，右键他，是同一段对话。

## 目录

```
vespera/
├── vespera-core/     纯逻辑：校历时钟、对话图、条件判定、音游谱面。不依赖 Bukkit，可单测
├── vespera-world/    地图资源：建筑布置清单、结构文件（LFS）、数据包
├── vespera-plugin/   Paper 插件：对话、状态、时钟、锚点、诊断
├── vespera-dev/      开发服务器：下载 Paper、装插件、起服、冒烟
├── docs/             方案、NPC 与地图、对话与交互、台本映射、合规
├── dev.sh            一条命令的入口
└── plugins.tsv       第三方插件清单（带校验和才自动下载）
```

四个模块的边界只有一句话：**core 不认识服务器，plugin 不认识文件系统布局，world 不认识代码，dev 不认识剧情。**
任何一处越界，都会让"单独验证某个部分"变成一件做不到的事。

## 三条硬约束

1. **原版客户端能直接加入。** 所以一切功能都在服务端：插件、原生 Dialog、服务端资源包（可选）。
   没有模组，没有客户端安装步骤。
2. **机制归插件，叙事归我们。** 八族的血势、转化、祭坛由 `mmSupernaturals` 说了算，本插件只读不写。
   剧情奖励是材料、通路、情报、盟友，不是数值。
3. **地图是数据，不是二进制。** 一栋楼是一个 `.schem`，摆在哪儿写在 `layouts/*.yml` 里。
   `region/` 永远不进 git。

## 合规第一原则

服务器形态已定：**私人 / 受邀，白名单，不公开，不推广，不收费。**

但私人不等于可以直说。三类只该被暗示、不该被点名的内容（身份、关系、冲突）走三道闸：

1. **不生成**——`content.yml` 三道闸默认全关，关着的线在客端不存在，也不留灰按钮；
2. **不命名**——游戏文本里不出现题材词、身体词、机制词；
3. **不描写**——镜头停在门口，所有事情发生在门外、在背后、在第二天早上。

细节在 [docs/06](docs/06-合规改写与内容边界.md)。一句总结：**把说出来的，换成发生过的。**

"借一段"变成"不能借"。

第三方插件（mmSupernaturals、Citizens、WorldEdit……）各有各的许可证，**一个都不在本仓库里**：
开发服务器按 `plugins.tsv` 在本地获取，校验和为空的一律只提示、不下载。详见 `docs/05-合规与版权.md`。
