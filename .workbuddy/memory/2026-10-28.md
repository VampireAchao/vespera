### 技术事实（核对过，别再猜）

- Minecraft Java 26.3，**要求 Java 25**（class file 69）。Paper 版本号格式已改为
  `26.3.build.<构建号>-<通道>`，不再是 `1.21.x-R0.1-SNAPSHOT`。pom 钉 `26.3.build.159-beta`。
- 原版 Dialog 自 1.21.6 起存在，Paper 从 1.21.7 起有 API。**对话选项框不需要资源包、不需要模组**。
  关键签名：`Dialog.create(f -> f.empty().base(b).type(t))`、`Audience#showDialog`、
  `DialogAction.customClick((view, audience) -> …, ClickCallback.Options.builder().build())`、
  `DialogBase.builder(...).pause(false)`、`DialogType.multiAction(buttons).columns(1).build()`。
  对话框是"屏幕"，会挡路 → 边走边聊要用 tellraw 可点击文本。
- 25 个 `Dialog.create` 的 lambda 参数是 `RegistryBuilderFactory`，`empty()` 返回 capture，链式调用可编译。
- mmSupernaturals（同为笔者项目，GPL-3.0）：`SuperNManager.get(Player)` 是 **static**，反射即可读
  `getType()/getPower()/isSuper()`。没有 ServicesManager API——建议上游加一个 `SuperNApi`。

### 踩到的坑（重要）

1. **Bukkit `YamlConfiguration#getValues(false)` 的嵌套值是 `MemorySection`，不是 `Map`。**
   core 层只吃 Map，必须在 plugin 层写 `plainMap()` 递归转换，否则剧本全部读不出来（冒烟测试抓到的）。
2. `vespera-core` 必须 **shade 进插件 jar**，否则 Bukkit classloader 找不到 → 插件被禁用。
   shade 的 `outputFile` 直接写 `server/plugins/vespera-plugin.jar`，避免 jar 插件先放一份未打包的。
3. 26.3 的 `DialogBase` 有 `pause(boolean)`（是否暂停游戏），没有单独的"锁移动"开关。
