# 结构文件放这里
#
# 一个 `.schem`（Sponge Schematic，WorldEdit 默认导出格式）就是一栋楼。
#
# 三条规矩：
#
# 1. **只放自己盖的。** 网上下载的建筑、别人的存档、付费地图包，一律不进这个目录。
#    建筑外观的著作权是真实存在的，而"我改了 30%"不是抗辩理由。
#
# 2. **大文件走 Git LFS。** 仓库根目录的 `.gitattributes` 已经把 `*.schem` 交给 LFS。
#    没有 LFS 的机器 clone 下来会得到指针文件，粘贴出来是一堆空方块——遇到这种情况
#    先 `git lfs install && git lfs pull`，不要怀疑 WorldEdit。
#
# 3. **命名带版本。** `gate-v1.schem`、`gate-v2.schem`。改结构不覆盖旧文件，因为
#    布置清单里可能还有别的地方在用 v1。删旧版本是单独一次提交，看得见。
#
# 导出时请遵守以下约定，粘贴才不会错位：
#   - 选中区域从建筑占地的最低角开始，Y 取地面那一格（不含基座）
#   - 朝向统一为"门朝南"（+Z），由布置清单里的 rotation 旋转
#   - 不要把周围地形、树、水一起选进去；地形是地形，建筑是建筑
