# 主城：流明陨城

一座 600×600 的中世纪城市，外加墙外的南港、竞技场、农田与北村。它同时是**出生点**、
**生存基地**和**剧情枢纽**——所以它不能只是"一排房子"，得先能住人，再谈好看。

---

## 一、先定四件事，其余都是推出来的

中世纪城市不是规划出来的，是**挤**出来的：城墙限定了边界，主街决定了地价，教堂和城堡
占掉最好的两块地，剩下的人在缝隙里盖房。按这个顺序排，城才会像城。

| 决定 | 内容 | 为什么 |
|---|---|---|
| **十字大街** | 南北、东西各一条，宽 16 格，从四座城门通到中央市集 | 城门对城门，是运货最短的路，也是人流最密的路 |
| **四座地标** | 教堂（东北）、城堡（西北）、市政厅（西）、行会（东） | 分别代表神权、军权、市政、商业——中世纪城市的四根柱子 |
| **环路** | 半径 240、160、84 的方形街网 | 把内城与外墙之间那圈住人的地方切成街区 |
| **城墙** | 600×600，厚 4，高 12，四门十二塔 | 它不是边界，是取景框：站在南门往里看，三层天际线要叠起来 |

天际线是设计过的：**圣座双塔 110 格 → 城堡主楼 50 格 → 市政厅钟塔 68 格 → 民居 13–17 格**。
从南门看进去，教堂在右、城堡在左、钟楼在正中偏西，三个高度错开，不会挤成一条线。

## 三、建筑语汇

不是"加点尖顶就叫中世纪"。这里用的每一样东西都有结构上的理由：

- **半木结构（half-timbering）**：石基 + 灰泥墙 + 深色木梁。梁不是花纹，是承重骨架；
  所以梁一定落在柱子上，窗一定开在梁格子之间。
- **出挑（jetty）**：二楼向街面探出一格。原因是临街地皮贵，向上要空间；副作用是街道
  显得更窄、更有压迫感——正好是 medieval 的味道。
- **陡坡屋顶**：坡度接近 45°，为了排雪。屋脊用台阶收头，山墙用灰泥填实并加斜撑。
- **扶壁与飞扶壁**：高墙会倒，所以每 9 格一道扶壁；中殿太高，扶壁撑不到，就用飞扶壁
  把力传到外侧。教堂的"骨架外露"就是这样来的。
- **雉堞与托石**：城垛不是装饰，是给守军站的地方；托石撑住外挑的垛口。
- **圆塔配锥顶**：圆形没有死角，锥顶排水最好。所以墙塔、角塔、城门塔全是圆身锥顶。
- **阶梯山墙**：市政厅的立面一级级收上去，是低地城市的做法，用来在窄立面上做出气势。

材料只有一套：石砖 / 圆石 / 深板岩瓦 / 红砖瓦 / 云杉与深橡木 / 四种灰泥 / 玻璃与铁。
限定材料是风格成立的前提——什么都能用，就什么都不像。

## 四、功能配套（半生存的那一半）

一座只能看的城，进服十分钟就没得玩了。所以每一块地都要能产出点什么：

| 需求 | 城里的答案 |
|---|---|
| 食物 | 城内 12 处菜园（小麦/胡萝卜/土豆/甜菜）、西田两块条田、谷仓、田边 16 头牲畜 |
| 木材 | 城外疏林、城内果园、建筑用云杉与深橡木 |
| 水 | 运河、喷泉、井（每个街区一口）、田边水渠 |
| 照明 | 主街每 28 格一盏灯、广场四角灯柱、屋内灯笼——夜里街上不刷怪 |
| 锻造 | 铁匠铺：炉子、铁砧、淬火桶、工作台、烟囱 |
| 存储 | 仓库与摊位上的桶、箱、货堆 |
| 居住 | 民居带 200 余栋，临街有店、院里有井 |
| 医疗/洗浴 | 澡堂（水池与柱廊）、图书馆（书墙与阅览台） |
| 娱乐 | 竞技场、酒馆（招牌、长凳、酒桶、篝火） |
| 防御 | 城墙、门楼、铁闸、箭孔；城堡另有台地与幕墙 |

**照明是硬需求**：不点灯，夜里城里会刷怪，玩家第一晚就会被堵在门口。所以灯不是装饰，
是安全设施。

## 五、技术：图和房子是同一份数据

```
MedievalCity（纯 Java，无 Bukkit）
   ├── CityApplier → 写进世界：选址 → 定基 → 整平 → 逐块 setBlockData
   └── IsoRenderer → 画成 PNG：同一批方块，等轴投影
```

- **选址**：先在 (0,0) 试，水域或坡地就沿 512 格网格找最干的一块，结果记在世界 PDC 里，
  下次不再找。城市中心不必是世界原点。
- **定基**：取场地外圈 24 个采样点的**中位数**——平均数会被一座山头带偏。
- **整平**：640×640 场地削高填低；竞技场、农田、村落、码头各整一小块。约 26 秒。
- **铺城**：约 150 万方块，15 秒。楼梯、台阶、栏杆、玻璃都保留方块状态。
- **重建**：`CITY_VERSION` 加一即可；`/vespera build city` 手动重建。

**为什么要整平**：顺着坡盖的房子，门会开在半空、墙脚会露出来。平台加挡土墙既是真事，
也最省事。
