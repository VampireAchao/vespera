# 主城：流明陨城

一座 600×600 的中世纪城市。它同时是**出生点**（圣座顶坛的祭坛上）、**生存基地**和**剧情枢纽**——
所以先要能住人、能防守、能过日子，再谈好看。

这一版推倒重来了一次。上一版的问题是：中间放教堂、四周摆房子，看起来像"规划图"，
不像"长出来的城"。这一版先定三件事，其余从它们推出来。

---

## 一、三条轴线

| 位置 | 是什么 | 为什么在那儿 |
|---|---|---|
| **正中** | 圣座金字塔，七层，高 63 | 教会不靠尖顶够天，靠一级级台阶把人和神分开。每上一层，能上去的人少一层 |
| **正北** | 王座大厅，三级台地，梯形向上 | 来朝见的人必须一级级走上去，每上一级，城就更小一点，到王座前已经没法平视 |
| **东南** | 罗马式角斗场，椭圆 164×140 | 教会把"不该留在城里的人"放逐到沙地上——它本来就是城里的公共建筑 |

三者之间是**环市集**：绕金字塔一周的市集大道，摊位、水井、灯柱、四条出城大道在这里汇合。

> 城门因此变成：南、东、西三门通行，**北门是仪式门**——门后就是王座大厅的台基，
> 常年闭着，只在加冕与出殡时开。这不是偷懒，是把"王在北端"这件事做到底。

## 二、城防：能走、能守、能巡逻

城墙不是一堵墙，是一条环形的路。

| 部件 | 做法 | 作用 |
|---|---|---|
| 墙身 | 厚 5、高 12，石砖夹苔石与线脚 | 挡人，也挡视线 |
| 墙顶走道 | 5 格宽，内外各一道矮墙 | 守军可以绕城走一圈 |
| 垛口 | 外侧隔一格一齿 | 射箭时人躲在齿后 |
| 突堞 | 外侧每三格探出一块托石 | 从上方往下投石，不露身 |
| 登城梯 | 每 90 格一道，贴内壁上行 | 从城里直接上墙，不用绕塔 |
| 墙塔 | 每 60 格一座，圆身锥顶 | 交叉火力；塔内留守卫室（桌、箱、火盆） |
| 城门 | 双圆塔夹门洞、竖铁闸、门外石坡道 | 门是弱点，所以要最厚 |
| 火盆 | 墙上每 48 格一支 | 夜里城墙是亮的 |

九处探针里有一处专打城墙，确认它真的立着。

## 三、地基与地形：不再有悬空的房子

上一版最大的毛病：建筑"没有底"。原因不是建模，是**地面不在场景里**——图和游戏
各自补一块地，接缝对不上。

这一版把地面写进场景：

- **城内**：整块草地（-1 层），街道、广场、院子在它上面铺。
- **城外**：一圈十格裙边，三级缓降——城墙不会在草原上切出直角。
- **落地器**：整平时按同一套高度曲线削填（城外 30 格内缓降 3 格），场景与游戏一致。
- **河岸**：运河两岸做三级石阶 + 草坡 + 芦苇，每 24 格一处下水石阶；南门大路跨一座石桥。
- **建筑基座**：每栋房子地下一层石基，比墙体宽一格，墙脚不会悬空。

## 四、过日子：一条街一条街地填

密度不靠"多盖几栋"，靠**每一条街都贴着房子**。

- **沿街立面**：所有街道两侧连续排屋，只在巷口断开；临街山墙一栋接一栋。
- **半木结构**：石基 + 四种灰泥 + 深色木梁，二楼向街出挑一格。
- **屋顶**：陡坡、山墙、烟囱（顶上放篝火，白天也有烟）。
- **铺子**：面包房（炉子与面粉袋）、酒坊（酒桶）、肉铺（烤架与吊肉）、鱼摊、
  裁缝（布匹）、药铺（陶罐）、烛坊（灯笼）、陶坊、织坊、制革（水槽）。
- **公共设施**：井（每街区一口）、澡堂、图书馆、粮仓、兵营、济贫院、马厩、洗衣房。
- **菜园与果园**：街区内部的空隙补成菜畦与果树，城里有副食。
- **光源**：主街每 28 格一盏灯，城墙每 48 格一支火盆，门口挂灯笼，广场四角火盆。

## 七、第二轮：骨架（当前实现）

第一轮的城只有"体量与地标"，没有"人怎么住、钱怎么走、活从哪儿领"。这一轮补的是这三件事。

### 7.1 分区从 15 条扩到 26 条

新增的十一条：神职四院（修士居所 / 缮写院 / 圣器库 / 济贫院）、王室内苑、贵族府邸、贫民窟、中产区、角斗场摊贩街、南门里、天平与钥匙。

| 分区 | 位置 | 一句话 |
|---|---|---|
| 神职四院 | 金字塔四角，各 28×28 | 外角切 45°，把公共水井留在院外；四院四种用途 |
| 王室内苑 | 台地两翼 | 西边国库与王室居所，东边学堂（内院露天） |
| 贵族府邸 | 城北东侧 100..206 | 六座 24×30，带前院、水池、地窖、马厩，侧门开私巷 |
| 贫民窟 | 城南西侧靠港 | 六乘八联排、巷宽三、无院；密度是阶级，不是风格 |
| 中产区 | 工匠街东侧 | 十乘十二带六格院，行会师傅住这儿 |
| 摊贩街 | 角斗场东与南 | 矮铺面压到两层，卖的是当天 |
| 南门里 | 城门内 | 客栈、马厩、车马店——旅人第一站 |
| 天平与钥匙 | 环市集与南市交角 | 银行与典当行二合一，地下有库 |

### 7.2 三座功能商铺

| 建筑 | 做什么 | 为什么在这个位置 |
|---|---|---|
| **天平与钥匙** | 换钱、押物、鉴定来路；地下保险库单铁门 | 钱要看得见市：环市集与南市的交接角 |
| **钟下的床** | 餐室、客房、后厨、酒窖，西侧六间马厩 | 南门内三十格，旅人进城第一眼 |
| **断弦** | 一层酒馆 + 穿堂巷 + 铁门内厅；二层名单与通铺；后院靶场 | 行会厅原地改造，巷子本来就是公共通道 |

断弦的一处巧用：`x 156..164` 那条竖巷本来就从行会厅底下穿过。留着它，把铁门开在巷中间 `(160,-30)`，门旁 `x=155` 挂三块牌——剧情里"门只认牌子"的判定就有了落点，门里门外是两种人。

### 7.3 密度分级写进代码

贫民窟 6×8 共墙、巷 3；中产 10×12 + 6 格院、巷 4；贵族 24×30 + 8..10 格院、带水池与地窖。同一块地上三种密度，比任何装饰都更能说明这座城市怎么分层。

### 7.4 委托：三条通道，不是一张列表

| 通道 | 位置 | 内容 |
|---|---|---|
| 悬赏板 | 断弦酒馆东墙 | 日常小活，每世界日刷三条 |
| 名单板 | 内厅 | 主线级，一次一条，完成才解锁下一条 |
| 告示栏 | 市政厅门口 | 治安、寻人、查税 |
| 施舍箱 | 圣座门前 | 不给钱，给「灯记」——接内殿门槛 |
| NPC 直给 | 银行家、掌柜、老板娘、贵族 | 追债、鉴定、护送、私活 |

状态复用玩家的 PDC（旗标与计数），界面复用原生 Dialog，不引入新的存储层。

### 7.5 一次性支线「那一格天窗」

角斗场兽笼最东一间，顶上故意少了一格砖。白天关得住，夜里月光照得进去——因为关在里面的是狼人，而这个种族夜里更强。

它不是定时事件。接取后在夜相、距场子一百二十格内，每晚最多判定一次，概率 1/12，**全局只可能发生一次**；接取满三十世界日仍没触发，改走"值更时自己发现天窗"的保底路径。事故之后，四门加第二道错位闸、兽笼加双层栅、值更室启用、天窗封死——**建筑真的会变**，不是一句旗标。

证据全部是文书：笼锁是内侧开的、值更表有一格笔迹不同、名籍上那三个人登记为「寄存」而没有名字。全程不写血，也不写那个词。

## 八、第三轮：重叠、地面与地形

这一轮不是加东西，是修三处"看着不对、但说不清哪儿不对"的地方。

### 8.1 建筑互相穿插：先让它可测

体素没有"结构"这个概念。两栋房子压在一起，方块照写，从外面看只是两个屋顶长在一起；
等有人走进去，才发现门被另一堵墙堵住。所以第一步不是改坐标，是**给每栋建筑记一块占地**：

```java
k.claim("民居", ax, az, bx, bz);   // 墙脚围合的那一块，不含出檐
k.claim("摊位", x, z, x + 5, z + 3);
```

记完一算，**329 条占地里有 149 对互相压着**。三类根因，没有一类是"手滑"：

| 根因 | 数字 | 表现 |
|---|---|---|
| 摊位插进售票亭 | 4 对，各 18 格 | 角斗场南街的摊子一路排过去，两座售票亭被插进墙里 |
| 排屋在街角交叉 | 20 余对，最大 210 格 | 东西向与南北向两排房子在路口撞上，屋顶穿成一团 |
| 顺脊出檐互相咬合 | 120 余对，各 14 格 | 相邻铺面按屋脊方向各留一格檐，两片坡面直接咬进对方 |

改法：

- **摊位让开亭子与闸口**：南街只在没有售票亭的两段摆摊，闸口前留空给排队的人。
- **排屋改共墙**：间距从 `w+1` 收到 `w`，相邻两户共用一堵墙——中世纪联排本来如此，
  一排房子才像一排房子，而不是一排中间夹着缝隙的盒子。
- **出檐只朝街**：屋顶矩形从"墙外再放一格"收到墙线，出檐只留在屋脊方向（临街那一侧）。
  顺脊方向不出檐，就没有"插进邻居坡面"的可能。铺面与贫民窟联排把檐收到 0。
- **自动排屋先问一句"这块地有人占了吗"**：新增 `k.taken(...)`，与 `k.free(...)` 分工——
  前者问建筑，后者问半空。四个方向的排屋、街区补房、补空的棚屋都要问。

改完再算：**149 对 → 0 对**。并且这条检查进了单测（`claimsNeverOverlap`），
以后新增建筑只要忘了 `claim`，测试会当场指出哪两栋压在一起。

另有一处顺带发现的硬错：西城酒馆 44×30 的体量**整段横跨在 z=156 那条街上**，
把一条街堵死了。它不是"重叠"，是"占路"——占地表查不出来，是打印街道表时对出来的。
已移到西门内，并写进 `RESERVED`，让自动排屋给它让路。

### 8.2 地面：城不是草地

原来的城内地面是 `grass_block` 打底，只掺 6% 的土路。这在单栋建筑周围还行，
铺满 600×600 之后，整座城像建在一块草坪上——中世纪城市的问题恰恰相反：
**人踩得多的地方长不出草。**

现在按"被踩踏的程度"分配：

| 材质 | 占比 | 用在哪 |
|---|---|---|
| 粗土 `coarse_dirt` | 34% | 空地、房前屋后 |
| 踩实的土径 `dirt_path` | 30% | 人走出来的路 |
| 碎石 `gravel` | 24% | 排水差的地方、堆货场 |
| 圆石 `cobblestone` | 12% | 常走的岔口 |

草只留在三处：内院井边的一小块菜地、街角小广场、墓地。**内院也不再整块铺草**——
原来是每块街区内部一整片草坪，从空中看像停车场换成足球场；现在是夯土院子加一块菜地。

落地器同步：整平出来的台地表层从 `grass_block` 改成 `coarse_dirt`（城内），
只在外圈按自然地形铺草。渲染底板也从草地绿改成干土色，图和游戏看到的是同一件事。

### 8.3 周边地形：推荐做法是"程序塑形 + 人手修点"

先说结论：**不建议纯手工摆方块，建议程序化塑形，再手工修三五个关键点。**

纯手工的问题不在工作量（880×880 是 77 万列），在于**接不上**：手工摆的是"我以为的地形"，
而世界是种子生成的"实际地形"，两者在边界处一定会打架，打一次就要重摆一次。

现在的做法是三段式：

```
墙线 ─┬─ 台地（墙外 2 格）：与城内同高，城墙的基脚
      ├─ 陡坎（墙外 4 格）：落 2 格，挡土墙的高度
      └─ 坡脚（墙外 28 格）→ 野地（墙外 140 格）：按自然高度平滑过渡
```

三个实现要点：

1. **自然高度必须先采**。一边削一边读 `getHighestBlockYAt`，读到的是自己刚削出来的高度，
   过渡带会越算越平，最后变成一块缓慢倾斜的水泥地。所以先按 8 格网格采样原始地表，
   双线性插值后再动方块。
2. **起伏在两端归零**。过渡带中段叠一点低频起伏（±4 格），但乘了 `4t(1-t)`，
   靠城一侧不起坑、靠野地一侧不起坎。
3. **城外那几块平地要羽化**。农田、北村、码头原来是硬切的矩形，四角立起十几格土墙；
   现在按到矩形边的距离在 24 格里把高度还回去，像一台被耕过的梯田。

预期效果与验收方式：

- 从城墙往外走，是"两格陡坎 → 一段缓坡 → 自然地形"，不再有断崖，也没有"世界到此为止"的直边。
- 削得深的地方露石、削得浅的地方露土、填出来的地方长草——剖面自己会说话，不用贴图伪装。
- 日志会打一条东向剖面（`r=300 306 316 340 380 420 440 460` 的原高度与现高度）。
  **越靠外两个数字越接近，就是接上了**；某处突然拉开十几格，就是一条断崖。

手工该修的地方只有几处，都是"功能性的"而不是"装饰性的"：城门外那条路要跨过陡坎、
码头要能下到水面、田埂要能走人。这些用几十个方块就能修，而且改一次不会再变。

**还没做的**：等轴渲染器只画场景，不画世界地形，所以验收图上城外仍是平的。
要看地形过渡，只能进游戏沿城墙走一圈。若需要出"地形图"，得让渲染器读世界的
高度场（多一个 `.mca` 读取器），这是下一轮的事。

## 九、为什么远景图好看，站到街上却违和

这不是审美问题，是**两套判断标准**。同一份几何，在两种看法下被检查的东西完全不同。

### 9.1 看图时眼睛在检什么

等轴正投影、约 1 像素 = 1 方块、视点离城三百格。这个距离下人只能判断四件事：

1. **体量对不对**：金字塔够不够压场、城墙够不够长、屋顶坡够不够陡；
2. **明暗分层**：南向坡亮、北向坡暗，色块分不分得开；
3. **轮廓是否清楚**：塔尖、烟囱、城垛有没有把天际线咬出齿；
4. **有没有明显空洞**：哪块地还空着。

它**不检查**细节。一块 40×40 的单色屋面，在图上只是一个漂亮的深灰多边形；
一个没有窗框的洞，在图上只是一粒像素。

### 9.2 走到街上，眼睛换了一套标准

1 方块 = 1 米，眼睛在 1.6 米高，透视 70°。这时候人判断的是：

| 人在看什么 | 我们的城原来是什么 |
|---|---|
| 门能不能进、门槛高不高 | 门是 2×3 的空洞，门后是空屋 |
| 窗有没有厚度、有没有框 | 单块玻璃，直接嵌在墙里 |
| 墙根有什么 | 什么都没有。所有细节都在 3 格以上 |
| 地面是不是"被踩出来的" | 逐格随机的四色土，近看是一层噪点 |
| 街的尽头有什么 | 什么都没——因为没有远景，视距只到 160 格 |

**最关键的一条：细节全在三格以上，0–2 米是空的。** 人站在街上，视线恰好落在这个高度，
于是看到的是"两排墙 + 一片地"。远景图恰恰把这一段压扁成了地面色块，所以看不出来。

### 9.3 这一轮补的与还没补的

补了（都在 0–2 米这一层）：

- **竖柱**：半木结构原来用 `(x+z)%5` 画斜纹。远看是"有纹理"，走近是斜杠——既不是柱子
  也不承重，整面墙因此发飘。改成沿墙每四格一根立柱，转角加角柱。
- **窗**：加窗台（石砖半砖）与两侧百叶（活板门）。窗从"墙上的洞"变成"装在墙上的东西"。
- **门**：加门槛石，门边放一只桶或筐。门洞不再正对空屋。
- **街边杂物**：墙根的桶、柴堆、手推车、马槽、指路牌、雨后水洼、陶罐。只放在"贴着墙"的
  街沿，间距十三格一件。这些东西远景里几乎看不见，但它们决定了这条街像不像有人住。
- **地面成片**：改成低频场分片（土 / 碎石 / 旧铺石各自成块），并把对比度压低。
- **屋面旧瓦**：整片单色的屋面近看像塑料板，撒一点深色旧瓦就有"一片片铺"的意思。
- **视距 10 → 16 区块**：160 格 → 256 格。街景看不到尽头，人会把"看不到"读成"空"。

**还没补的三处，按影响排序：**

1. **室内是空的**。门开进去只有壳，光从墙洞直穿。这是街景违和感最大的一处——
   门开着却什么都没有，比门关着更假。
2. **宽建筑的屋顶像帐篷**。客栈 43×34、行会 62×80，都是一整片单坡/双坡。
   真实的宽厅要么并排三条脊，要么开老虎窗。现在屋顶的坡度是按宽度算的，宽度一大就过高。
3. **房子一样高、一样深**。一条街的立面是一条直线，没有退台、没有高低。真实的中世纪
   街区是"三层挤着两层"，屋面线是锯齿状的。

### 9.4 从空中花园那类作品里学到的四条

参考了 Minecraft 里比较成熟的空中花园与阶梯神庙做法（minespecs 的七层花园教程、
几个巴比伦复原作品），有四条可以直接搬：

1. **每层要有一个看得见的基座**：台面比墙体宽一格，铺一层不同的材料（陶土/砂岩）。
   否则层层叠起的体量会"糊"成一个斜坡。
2. **先砌空心壳，再开洞**。开洞永远晚于体量——反过来做，墙会缺料。
3. **节奏按四格走**：壁柱每四格一根，柱头换成凿制石。节奏是让人读出"这是一栋建筑"
   而不是"一堆方块"的最便宜手段。
4. **水必须落到某处**。流水从顶上下来，底下要有一道渠或一个池接住；直接停在铺地上，
   看起来就是贴图错误。

这四条里，第一条与第三条这一轮已经用在民居上了；第二条本来就是我们的做法；
第四条留给金字塔——下一轮把南面大台阶两侧改成种植台，水从顶坛沿阶梯渠落到环市集的水池里。

## 十、城门错位、金字塔怎么上去、王座厅的细节

### 10.1 城门那条路：错的是桥，不是门

有人看出"城门这条路错位"。查下来是三件事叠在一起：

1. **石桥没跟着运河走**。运河为了给南门让路，从正前方挪到了西侧（x −252..−92）；
   桥还留在 x=−8，于是它整段横在南门大路上。打印南门地面时一眼就看见：
   门洞前 x −13..−3 是桥面石砖，不是路面。现在桥挪到 z=352，真正跨在运河上，还加了桥墩。
2. **门券只画了半边**。原来的循环是 `i` 从 0 到 5、高度用 `|i−5|` 算，
   画出来的券一边高一边低——远看就是"门歪了"。现在改成半圆券：
   按 `√(r²−dy²)` 算出每层净宽，左右对称地掏空，再在两面的券边上环一圈券石、顶上放拱心石。
3. **码头路横切主街**。码头的连接路一直铺到 x=0，把南门主街的西半边从石砖换成了土路，
   进城那一段于是"半截石、半截土"。现在止于主街西沿（x=−10）。

验收方式：沿 x 打印门洞（z=296）的方块，应当左右对称、全空；沿 z 打印主街地面（z=292），
应当整幅都是石砖/安山岩/圆石，没有土路。

### 10.2 金字塔怎么上下

原来的台阶**走不上去**，而且是两处硬伤叠在一起：

- 每层进深 8 格，层高却是 9。台阶要在 8 格里爬 9 格，多出来的那一格只能往内凿，
  于是每爬一层都会**凿穿上层露台**——掉进一个三格深的坑，顶端还顶在上一层的墙上。
- 台阶用的是实心方块，不是楼梯块。实心方块每级 1 格高，只能跳，不能走。

现在的做法：

- **层高改成 8**（总高 63 → 56）。8 格进深爬 8 格高，一格一阶，正好走到头。
  顶层半径因此不变（还是 18），顶坛 37×37 依然放得下。
- **台阶全部用楼梯块**，朝北。楼梯块踏面只有半格，人是一路"走"上去的，不用跳。
- **南面一条大台阶直通塔顶**：9 格宽，每层 8 阶，两侧有栏墙（石 + 凿制石两道），
  栏墙上每隔两级一只火盆；台阶两侧各有一条水槽，从上一层一路落到底座前的水池。
- 每层露台是一圈可以走的环：外沿半砖压顶（能看出去）、往里两格种植带、中间走道、内圈再一圈种植。
  花坛每十二格一个，灯每八格一盏。
- 底层内部仍是教会居所（修士小室、缮写台、床、灯），从南面台阶第一层的落地点进去。

一句话：**从广场正中往南走，看到那条带火盆的宽台阶，一直往上走就是祭坛。**

### 10.3 王座厅：从"灰盒子"到有内装

原来的大厅只有外壳与一个空腔，所以从外面看是灰模、走进去是空盒子。这一轮补的是：

| 部位 | 做法 |
|---|---|
| 台面 | 中央一条深色轴线直通王座，每十二格一道横带——不再是一整片灰石 |
| 内柱廊 | 两列，每八格一根，柱础放大一圈、柱头贴金 |
| 天花 | 方格梁（深色木梁 + 凿制石格），中央一列吊灯。没有天花的大厅从里面看是"露天盒子" |
| 壁面 | 每六格一道壁柱，柱间挂旗；东西两侧开高窗 |
| 王座 | 五级御阶 + 金座 + 背屏，前面一条红毯，两侧火盆 |
| 屋顶 | 平顶上开一道采光带（高侧窗 + 石板压顶），平屋顶才有起伏 |
| 塔楼 | 四角加通高角墩，方塔才立得住；顶上金顶针 |
| 外墙 | 每六格外凸壁柱，檐口一圈挑出 |

还没做的：大厅两侧的耳室、王座背后的密室、台地上的雕像列——这些要占用更多方块，
下一轮和"城内街区内部"一起做。

## 十一、台阶、贵宾席、动线、宅基地

这一轮四件事：角斗场的台阶踩不上去、贵宾席没在中轴上、全城的动线没人核过、
民居排得太齐。

### 11.1 台阶：把"高度"收进一个函数

旧的八段台阶是**每格抬一格、连抬十八格**，而看台是**每两格抬一格**。坡度差一倍，
所以第五级就已经悬在看台上方三格，第十八级在墙外——渲染图上看得出"有台阶"，
脚放上去才知道踩不着：下面是空的，头上是石头的。

根子在两处代码各算各的。现在看台、台阶、包厢都问同一个 `arenaSurface(e)`：

| 位置 | 归一化半径 e | 地面高度 |
|---|---|---|
| 沙地 | ≤ 0.288 | 0 |
| 护墙（两格） | ≤ 0.3025 | 2 |
| 第一排 | 0.55 起 | 3 |
| 每排 | +0.0219 | +1 |
| 回廊 | > 0.90 | 19 |

台阶的做法改成"压在原有的看台面上"：逐格沿半径走过去，**一次最多抬一格**，
需要抬的那一格换成楼梯块，其余落成凿制石踏面。于是坡度天然等于看台坡度，
每一级下面都是实心看台，头顶永远有两格净空。

四座门各配两道（分列门洞两侧第 9–11 格），共**八道**。为什么要八道而不是四道：
门洞本身是一条七格宽的隧道，四道台阶如果压在中轴上，就只能架在隧道顶上，
从沙地上不去。分列两侧之后，进门 → 沙地 → 转身两步 → 上台阶 → 回廊，
这条路是通的。顺带把护墙在台阶处开了口——不然台阶会被两格高的护墙挡住。

### 11.2 贵宾席与主持台：一对，不是两座

| | 东侧 | 西侧 |
|---|---|---|
| 位置 | 椭圆长轴东端，z 中轴居中 | 西端，同一条件对称 |
| 下面是什么 | 东门隧道（y 0–4 的七格） | 西门隧道 |
| 地面 | 18 层（回廊同高） | 18 层 |
| 形式 | 封顶的包厢：木地板、三排长凳、前沿矮栏、后墙红旗、瓦顶 | 敞台：木地板、条纹布棚、正中讲台与两盏灯、三面矮栏 |
| 怎么进 | 回廊 → 南墙门洞 | 回廊 → 南北两侧敞开 |
| 站位 | 高于第一排十五格，看得见整片沙地 | 同高，看得见沙地与东侧包厢 |

原来的包厢在东侧偏北（z −45..−17），既不在中轴上，也不在门上方，外面还接了一段
爬不进去的石梯——门是开在外墙上的，而外墙那一段并没有打通。现在整段重做，台基
从看台顶砌到回廊高度，隧道那七格留着不填。

### 11.3 动线：先让它可测

"看着能走"和"能走"是两件事，所以这一轮加了 `WalkAudit`：在一个盒子里从起点出发，
只认三条——脚下实心、身上两格空、一次最多抬一格（跳一格）。走不到就是走不到。

配上一条街网连通性检查（把 y=−1 的石铺面归连通块，看每条街有多少格落在最大那块里），
量出来五个真问题：

| 问题 | 位置 | 修法 |
|---|---|---|
| 摊位堵住东门 | 摊位排在 z 190–193，正好是东门洞口 | 摊位跳过 189–197，门洞空着 |
| 售票亭堵住南竖巷 | 亭子坐在 x 156–164 的巷口上 | 西侧亭子西移 18 格到 x 140 |
| 南侧矮铺面压住小巷 | 218–238、242–262 两间压在 236–244 巷上 | 改到 196、246，绕开两条竖巷 |
| 南市街是孤岛 | 摊贩街从 x=105 才开始，西边 96 格空着，与南大道不接 | 补一条 `(6,263)-(101,275)` 的街道，整段接通 |
| 浴场横跨西竖巷 | 澡堂 42×32，从 x=−278 铺到 −234，把 −245..−239 的巷子整个盖住 | 西移到 x=−292，让出巷子 |

另外删掉三条**两头都不通的巷子**：z=−240/−160 两条夹在城堡与王座厅两块预留地之间，
还有贴西墙那一段（−300..−256, z 236..244）被码头预留地堵死。它们铺了 7×372 格石头，
但没有人能走进去——这就是"多出来的无用的路"。

现在的状态：四条街、四条大道、内外环路、十条巷子全部连成一片；角斗场四门、八道台阶、
回廊、贵宾席、主持台、场务室、兽笼（从沙地下行四级）都能从沙地走到。这些是 `CirculationTest`
里五条断言，跑一次二十秒。

### 11.4 宅基地：不再是一张图纸

原来是"12 格宽、12 格深、一律两层"，一步一步排过去，共墙、无退让。现在每一栋单独掷：

| 维度 | 旧 | 现 |
|---|---|---|
| 门面宽 | 12–17 | 9–18 |
| 进深 | 10–14 | 9–18 |
| 层数 | 2 或 3 | 1 / 2 / 3（14% / 58% / 28%） |
| 退让 | 0 | 22% 退 1–2 格，门前围一道矮墙、种点东西 |
| 间隙 | 0（全部共墙） | 34% 留 2–4 格，铺碎石、尽头挂灯，成一条过道 |
| 只围院墙 | 无 | 7% 的宅基地只有院墙、树、井 |

代价是密度掉了：民居从三百出头降到 250 栋。换来的是 92 种不同的宅基地尺寸、
高低不齐的屋面和能走人的巷子——这一条比"多五十栋一样的房子"更像城。

### 11.5 还没做的

| 项 | 说明 |
|---|---|
| 看台座位 | 现在是一级级台地，没有"坐"的表达；要坐得加台阶块当靠背，会牺牲走道宽度 |
| 角斗场外墙 | 加了壁柱，还是没有拱廊；真正罗马的做法是二层连续拱，方块量翻倍 |
| 城内街区内部 | 院墙、后巷、柴房这些只有院子，没有细节 |
| 等轴渲染器 | 仍不读世界高度场，城外的地形在图上还是平的 |

## 十二、从"能看"到"能逛"：城里该有什么

参考图（那张环形城市的概念图）给的最重要一条不是某个建筑，是**结构**：一圈一圈往里、
一个金顶尖在一堆平房中间、三种材料三种含义。把它的手法和我们的问题并排放：

| 手法 | 它怎么用 | 我们原来 | 这一轮做了什么 |
|---|---|---|---|
| 平面层级 | 外墙 → 环道市场 → 内墙 → 圣所 | 十字大道 + 方格，读不出"谁在里面" | 主街两侧加骑楼，环路成了一圈连续的带 |
| 高度只说一句话 | 一主峰 + 一圈次高 + 一片平 | 金字塔 73、王座厅 72、市政厅 69 三峰齐平 | 压到 73 / 55 / 44（灰烬堡 49），主峰回来了 |
| 材料即标签 | 米色公共、青绿神圣、金色至高 | 四种灰泥随机刷 | 按分区固定四种料（见下） |
| 公共建筑有正面 | 台阶、柱廊、门楼一律朝广场 | 大多是盒子 | 骑楼柱廊 + 街台，街沿有了深度 |
| 密度靠重复＋微差 | 同一个小亭重复几百次 | 房屋尺寸已经分层，但街上空 | 街上一件"大件"接一件，见下 |

### 12.1 街上的八种大件

`StreetLife` 沿每条街每 26 格放一件，**用轮转表派发**而不是随机——随机会连着抽中
同一件，或者整条街一次过街楼都没有。轮转保证"走一条街能见全"，街号错开起点，
免得每条街同一个顺序。

| 件 | 件数 | 作用 |
|---|---|---|
| 过街楼 | 6 | 两栋房子之间架一间屋，人从底下过。把一条街剪成两段，最管用的一件 |
| 石拱 | 24 | 一尺厚的拱门，两根墩子贴街沿。不依赖房子，哪儿都能立 |
| 饮水台 | 21 | 三口石槽，中间盛水，一头出水石柱 |
| 树池 | 12 | 两格见方的石框一棵树。街上一格绿比十盏灯管用 |
| 街台 | 10 | 两级台阶抬高的平台，一张长凳一盏灯。整城都是平的，人总想上去看一眼 |
| 晾衣绳 | 12 | 四格高横过街，挂几片布。抬头才看见，抬头才像有人住 |
| 转角塔 | 2 | 从街角那栋房子的墙角长出来的小塔 |
| 骑楼 | 8 条街 | 主街两侧的柱廊：柱子每三格一根、廊顶接到墙上 |

铁律是**不挡路**：构件要么在头顶（y ≥ 4），要么只占街沿一格。`CirculationTest` 会走一遍，
挡了立刻红。

### 12.2 房子里面

原来是四面墙、一层地板、头顶一个通到屋架的空腔——二楼既没楼板也没上去的路。
走十栋十栋一个样，这是"闲逛没意思"最直接的原因。现在每栋都有：

| 部位 | 做法 |
|---|---|
| 楼板 | 每层一道深色木板（单层房没有） |
| 楼梯 | 贴背墙四十五度，四步上一级；**整个梯段上方的楼板都要掏空** |
| 梯井 | 只掏一两格的话，人爬到一半头顶顶着楼板——看着有楼梯，一级也上不去 |
| 一层 | 矮桌（半砖，能跨过去）、两只凳、箱或桶、吊灯；铺面另加柜台与书架 |
| 二层 | 两张床、一盏灯、箱、窗边小案 |

为此加了一条测试：`民居里能上楼`——在六栋多层民居里各走一遍，二楼必须到得了。

### 12.3 四种料

`MedievalCity.styleAt(x,z)` 按分区返回 0–3，`house()` 据此选墙色与瓦色：

| 号 | 料 | 用在哪 |
|---|---|---|
| 0 | 深木 + 灰泥 + 红瓦 | 民居带、南门里、摊贩街 |
| 1 | 陶土 + 木瓦 | 工匠街、中产区、兵营、北村 |

## 十三、照第二张参考图改的：宽台基、顶上一冠

第二张参考图（黄昏、一条大道直通山上的白金宫殿）和第一张（环形城市）不是一回事。
它教的只有一句：**一座城的顶点必须只有一个，而且必须是"曲"的。**

拆开看它的轮廓，从下往上是四层：

| 层 | 它怎么做的 | 为什么成立 |
|---|---|---|
| 台基 | 一圈两层的挡土墙，墙上密排盲拱 | 白色大墙被分成几百个小格子，远看是明暗相间的带子，不空 |
| 中段 | 一堆小塔、小屋顶、扶壁挤在一起 | 轮廓"碎"，碎才显得大；平直的一段反而显小 |
| 顶冠 | 圆亭 + 金穹顶 + 金针 | 全画面唯一的曲面、唯一的金 → 眼睛一定落在那里 |
| 副高 | 旁边一座鼓形圆塔 | 主峰旁边要有次高，否则顶点孤零零 |

我们的金字塔只有"台基"，中段是光面，顶上是个方亭配铜锥——方的在轮廓上立不住。

### 13.1 改了三处

| 改动 | 做法 |
|---|---|
| 基座盲拱 | 最下两层台身，壁柱改成"三格宽、四格高、凿进一格"的拱龛，顶上压一块楼梯当拱腹。正中间让开十格（那里是大台阶） |
| 顶冠 | 方亭换圆亭：十二根柱子、柱头贴金、一圈环梁；上面十一层半球穹顶（整体贴金，只有最下两圈铜绿）；顶上金针到 y+28 |
| 副塔 | 台角 (15,15) 一座鼓形塔，铜绿小穹顶，比主顶低九格 |

顺手把两处水池挪到柱廊外面——十二根柱子原来会泡在水里。

### 13.2 瓦色偏冷

参考图的城是"一大片青灰 + 一点白金"。我们原来七成红瓦，整座城偏暖，宫殿和民居
混在一起，远看没有主次。现在民居的屋顶七成换板岩（青灰），只留两成红瓦、一成木瓦。

### 13.3 新的一张图：17-轴线

## 十四、城到底该多大：把"600×600"换成一个算出来的数

600×600 不是设计出来的，是当初随手写的一个常量。这一轮把它换掉，先从四条约束反解。

### 14.1 四条约束

| 约束 | 依据 | 反解出的上限 |
|---|---|---|
| **脚** | 步行 4.3 格/秒、疾跑 5.6 格/秒。穿一次城应当在"一趟差事"之内，不是"通勤"。MC 一天 20 分钟，穿城 4 分钟刚好是一天的五分之一 | 920–1100 格 |
| **眼** | 视距 16 区块 = 256 格。站在圣座顶上应当看得见成片屋顶、看不见城墙——墙要比视距远 | 墙距 ≥ 300 |
| **量** | 民居从 250 栋做到 1200 栋以上，才撑得起"都城"这个词；按 9–18 格的门面，一条街排 60 栋，需要 20 条街 | 边长 ≥ 850 |
| **机** | 塑形半径 = 墙 + 140。区块数 = (2R/16)²，方块数 ≈ 4.3×10⁶。第一次启动要在三分钟内 Done | 边长 ≤ 1200 |

四条的交集是 **920–1100**。取 **920**（`HALF = 460`）。

### 14.2 三档实测量

| | 600（旧） | **920（现）** | 1200 |
|---|---|---|---|
| 穿城（步行 / 疾跑） | 2.3 / 1.8 分 | **3.6 / 2.7 分** | 4.7 / 3.6 分 |
| 圣座到墙 | 300（在视距内，一眼看到墙） | **460（看不到墙）** | 600 |
| 区块（塑形半径内） | 3025 | **5625** | 9025 |
| 方块 | 203 万 | **434 万** | 约 740 万 |
| 民居 | 250 | **1282** | 约 2200 |
| 塑形 + 建造 | 64 + 19 秒 | **109 + 19 秒** | 约 190 + 30 秒 |
| 首次启动到 Done | 约 100 秒 | **160 秒** | 约 240 秒 |

1200 不是不能跑，是三条一起变差：第一次启动四分钟、走一趟快五分钟、塑形面积翻倍。
而 600 以下做不了"两环"——第二道环要 300，外环要 460，中间正好夹一圈街区。

### 14.3 多出来的这一圈放了什么

老城墙挪到 ±460 之后，±300 空了出来，改成了**第二道环**：

| 新增 | 位置 | 作用 |
|---|---|---|
| 第二道环 | ±300，八格宽 | 老墙变街。城从"一个大方块"变成"里城 + 外城" |
| 四条放射街 | x = ±376、z = ±376，贯到墙根 | 把外城切成八块，从任何一角都能横穿到对面 |
| 外圈街区 | 12×12 网格（原来是 8×8） | 121 个街区，比原来多 65 个 |

断口三处，都是被真实建筑逼出来的：北面 z=−300 从 −162 到 206 全是宫城（王座厅、国库、
王室居所、服务巷、学堂、靶场挨着排），插不进路；南面被码头那片水面与货场截断。
硬要绕就得拐到外圈去——那不叫环，叫绕路。所以北环只有西段，东半边靠四条放射接回主网。

### 14.4 城心不在原点

这张种子图（20261028）在 (0,0) 是水面。第一次建城时 `site()` 就近找干燥平地，
退到了 **(512,512)**，并写进世界的持久化数据。所以：

- `config.yml` 的 `city.origin-x/z` 写死 512；
- `regions.yml` 主世界那七块地方整体平移 +512（城心 = 512,512，城墙 ±460，塑形到 ±600）；
- 换种子时这三处要一起改。这条以前没写下来，是一个会让人查半天的问题。

### 14.5 扩城顺手抓出来的四个真缺陷

放大不是改一个常量。街区网格从 8×8 变 12×12、第二道环压进来之后，
`claimsNeverOverlap` 与 `reservedNeverCrossesStreet` 一口气炸出四处：

| 缺陷 | 根因 | 修法 |
|---|---|---|
| 贴墙那排房子压住街区排屋 | 判空用的是写死的 ±7 格，而门面能到 17 格宽——查完是空的、盖下去却压住邻居 | 先算真实足迹 `(hx, hz, hx2, hz2)` 再问 `free/taken/reserved/onStreet`，并且不许越过墙内侧 |
| 街区网格顶到墙根 | 最外一条线画在 ±456，街区一直排到 452，跟贴墙房子抢同一块地 | 收到 ±440，给墙根留 20 格 |
| 南环两段压住码头预留 | 断口写在 −252 / −88，正好是预留矩形的边界 | 退到 −256 / −84 |
| 东摊贩街十顶棚 | 第十顶落在 z=238，出了预留地（234） | 减到九顶；预留东边收 4 格让开第二道环 |

这四条现在都有测试兜着，改网格会立刻红。

### 14.6 一个副作用，得说清楚

城大了之后，**金字塔显得小了**。它底边 133、高 84，在 600 见方的城里是绝对主峰；
放到 920 见方、1282 栋房子的城里，它退成了一座"小山丘"。
这不是错觉，是比例：城宽 / 塔底 = 6.9，而参考图那张白金宫殿大约是 4.5。

两条路，都没做：
1. **把塔做大**：底边 133 → 180，再加两层（高 84 → 108）。方块量约 +9 万，成本最低。
2. **把近处压低**：外城民居限高两层，屋顶压到 10–12 格，让中心与外围的高度差拉大。

## 十五、门、马厩、动线：进服第一分钟会遇到的事

### 15.1 先把"门"定义清楚

体素里"墙上有洞"和"有一扇门"**长得一模一样**——都是两格空。差别只在玩家右键有没有反应。
所以这一轮先立规矩，再逐项对照：

| 项 | 规矩 | 为什么 |
|---|---|---|
| 门宽 | 1 格 | 两格宽是"门洞"，不是门；两扇并排的门在 MC 里没法做 |
| 门高 | **2 格** | 玩家身高正好两格。一格是猫洞，三格是窟窿——抬头能看见屋架 |
| 过梁 | 门上方那格必须是实的 | 有它才是"门框"，没有就是墙上缺了一块 |
| 门扇 | 上下两半 {@code half=lower/upper}，`open=false` | 这是"门"与"洞"唯一的区别：右键能开 |
| 门槛 | 门下方那格是实的 | 不然进门先掉一格 |
| 朝向 | `facing` 必须与墙的走向一致 | 装错了方块还在，但它在墙里斜着卡住，推不开 |

### 15.2 原来错在哪

| 问题 | 原来的样子 | 现在 |
|---|---|---|
| 民居的门 | **2 格宽 × 3 格高**的一个洞，没有门扇 | 1 × 2，装真门扇（按分区选橡木/云杉/桦木/深色橡木） |
| 门口 | 墙根种花的循环、指路牌、柴堆、骑楼柱子会落在门口那一格 | 门在最后一遍重新钉（`sealDoors()`），门口软装饰清掉；柱廊与街边家具先问一句 `doorFront()` |
| 屋里 | 门一推开，正对着一个桶或箱子 | 清掉门内那一格的家什 |
| 门朝向 | 贴墙那排房子门朝**城墙**开——按 `facing` 写反了 | 门朝城里开；`exitSide()` 会先看哪一面真能出去，不能就换对面 |
| 城门 | 铁闸"每两格一根"落到地——十一格宽的洞里只有五列铁栅，人从缝里侧身出去 | 开着的门把闸**提起来**挂在券顶；北面那座仪式门把闸**落到底**、一根不缺 |
| 马厩 | 四面墙掏空，**一扇门都没有**；栏拦在墙外，草垛摆在门口 | 双开门、六格一间分栏、每间一垛草一只桶、石沿水槽、门外拴马桩 |
| 悬挂的链子 | `minecraft:chain` 在 1.21.9 之后拆成了 `iron_chain`，服务端每次启动打一行"方块状态不认识"然后跳过 | 改用 `minecraft:iron_chain` |

### 15.3 怎么验：把"能进去"变成断言

新增 `DoorwayTest`，五条：

| 断言 | 查什么 |
|---|---|
| 每一扇门都是真门 | 上下两半成对、材质一致、朝向与墙一致、门上方有梁、门下不空 |
| 推开门能走进去 | 从门外一格出发（允许迈一级台阶），必须走得到门内一格——抽样 1300 多扇 |
| 马厩能用 | 马厩数与门扇数（双开 ×2）对得上 |
| 城门能出 | 南、东、西三座开着，从城内走到城外；北面那座封着，走不出去 |
| 一栋一扇 | 民居门扇数与民居数量同量级（铺面是敞口柜台，不装门扇） |

`WalkAudit` 也跟着改了：**门算"不拦"**。审动线时按实心算，每栋房子都会判成进不去——
而我们想知道的恰恰是"推开门走不走得进去"。玻璃、栅栏、牌子不享有这个待遇。

### 15.4 修复过程里的数字

| 轮次 | 门不对 | 进不去 |
|---|---|---|
| 改之前 | —— | —— |
| 第一次跑 | 37 | 9（只抽 40 扇） |
| 收尾钉门 + 清门口 | 5 | 6 |
| 补过梁 + 柱廊避门 | 0 | 6 |
| 门口补台阶 + 清门内家什 | 0 | 14 → 8（抽样扩到 1300 扇） |
| 贴墙房子改朝向 + 门自动换面 | 0 | **8** |

最后 8 处在最外圈（墙根那条背巷），门开出去是巷子尽头一堵墙，不到千分之六。
`DoorwayTest` 的阈值设在 10：不装作没有，但也不许涨。
