# 05 · 合规与版权

> 这篇是**工程侧的规避清单**，不是法律意见。公开运营前请让法务过一遍；下面每一条都写了
> "为什么会有风险"，因为不知道原因的人守不住规则。

---

## 一、三条红线

| 红线 | 具体是什么 | 一旦越线的后果 |
|---|---|---|
| **正版与客户端** | 不得分发、修改、破解 Minecraft 客户端或服务端核心；不得为盗版客户端提供验证绕过 | 微软/摩江的侵权主张；网易作为中国大陆独家运营方的投诉 |
| **不冒充官方** | 不得使用 Mojang / Microsoft / 网易 的名称、商标、Logo 暗示关联或授权 | 商标侵权；平台下架 |
| **未成年人内容** | 性别转换、同性恋爱、校园霸凌题材 + 面向未成年人传播 + 任何形式的付费 | 家长投诉 → 平台/监管介入；这是本项目最现实的死亡方式 |

三条里前两条靠纪律，第三条靠**产品设计**。而第三条恰恰是本项目题材的中心，所以它不是"注意一下"，
是"必须先解决才能上线"。

---

## 二、正版验证：`online-mode=true`

| 项 | 决定 | 原因 |
|---|---|---|
| 线上服务器 | `online-mode=true`，`enforce-secure-profile=true` | 只接受持有正版账号的玩家。离线验证（`false`）意味着任何人可以冒名顶替任何 ID，等于把账号摆在门口 |
| 开发服务器 | 默认也是 `true`，要关必须显式加参数 | 开发时的"方便"最容易变成上线时的"忘了改" |
| 客户端 | **不提供、不推荐、不打包** | 玩家自己用官方启动器。我们不碰客户端，这是最干净的一条线 |
| 服务端核心 | 不随仓库分发，构建时从 PaperMC 官方下载 | Paper 是 GPL-3.0，分发它需要连带源码承诺；不打包就没有这个义务 |

`dev.sh` 的默认参数就是按这个写的：`vespera.onlineMode=true`。

## 三、EULA 与商业化

Minecraft EULA 允许运营服务器，也允许收一定的费用，但对"卖什么"有明确边界。
**具体条款以官方文本为准**，工程侧只需要守住三条保守原则：

1. **不卖影响平衡的东西**——不卖装备、不卖血势、不卖"跳过剧情"、不卖种族转换。
2. **不卖随机**——没有抽卡、没有宝箱、没有概率商品。
3. **不做"付费才能继续"**——任何章节、任何结局，付不付费都能到达。

本项目的设计恰好天然合规：奖励是材料、通路、情报，不是数值。**这条设计约束同时也是合规约束**，
这是它值得守的原因。

> 如果将来要做"支持服务器"的通道，正确形态是：纯装饰（称号、粒子效果、宠物外观）+ 明码标价 +
> 不影响任何人。即便如此，也要先确认所在地的消费者权益与退款规则。

## 四、网易：中国大陆的特殊性

Facts：

- Minecraft 在中国大陆由**网易**独家代理运营（中国版）。
- Java 版的国际版由 Mojang/Microsoft 运营，第三方 Java 服务器在世界范围内是常态。
- 但"在中国大陆公开运营一个 Minecraft 服务器"，法律上落入网络游戏监管，而不是"技术爱好者自建服"。

因此四条规避（都很具体）：

| 规避 | 做法 |
|---|---|
| 不用网易的任何东西 | 不用中国版客户端、不用其资源包/模组/地图、不接其 SDK、不导流到其平台 |
| 不蹭商标 | 服务名、域名、LOGO、宣传语里不出现"我的世界""Minecraft""网易"；用原创名（本项目：维斯佩拉 / Vespera） |
| 不暗示授权 | 启动页与 README 都放同一句免责声明（见文末模板），一字不改 |
| 不做公开推广 | 私人/受邀测试阶段不投广告、不做应用商店分发、不做付费推广 |

## 五、未成年人：最现实的一条

这是"家长维权"的具体形态。三件事最容易被投诉，本项目三件都沾：

| 题材 | 风险 | 缓解（必须做，不是可选） |
|---|---|---|
| 性别转换 | 被解读为"诱导"；在部分地区是政治敏感表达 | 内容开关默认**关**；不作为宣传卖点；处理原则是"社会问题，不是笑点"（设计书已写） |
| 同性恋爱 | 公开传播在部分地区有政策风险 | 同上；不做成"卖点"，只作为角色线之一 |
| 校园霸凌 | 呈现方式容易被指"教唆"或"二次伤害" | 霸凌在文本里始终是错的；必须给反制路径且反制有回报；不展示细节 |

产品侧的六件事：

1. **准入**：16+ 或 18+，注册时明确告知题材；不做面向未成年人的宣传。
2. **内容开关**：每条敏感线一个开关，默认关；开了要二次确认。
3. **回避机制**：已在设计书 11.6 与代码 `avoid` 里落地——跳过不惩罚。
4. **不收费**：只要不收钱，"诱导消费"这条投诉就不成立。
5. **实名与防沉迷**：若面向公众开放，按现行规定接入（这也是为什么"私人测试"是更现实的起点）。
6. **举报与家长通道**：一个能收到的邮箱 + 一条"家长可申请删除其子女数据"的流程。

**最硬的一条：在中国大陆公开运营网络游戏需要版号。** 没有版号的公开运营，无论内容多干净，
都属于违规运营。这不是可以靠"注意措辞"绕开的问题——它决定了本项目的默认形态应该是
**私人 / 受邀测试**，而不是公开服。

### 已定的形态：私人 / 受邀

服务器形态已经定下：白名单、不公开、不推广、不收费，大概率只有作者一个人会进。

这个形态把上面六条里的四条直接消掉了：

| 条 | 私人形态下 | 说明 |
|---|---|---|
| 准入年龄 | 不再需要硬门槛 | 没有公开入口，就没有"面向未成年人传播"这件事 |
| 实名与防沉迷 | 不需要 | 非公开运营 |
| 版号 | 不需要 | 同上 |
| 不收费 | 保持 | 一旦收费，性质就变了 |
| 内容开关 | **仍然要做，且默认全关** | 私人不等于可以直说，见 `docs/06` |
| 回避机制 | **仍然要做** | 它是文本纪律，不是合规补丁 |

**但"私人"只解决"运营"这一层，不解决"内容"这一层。**

内容那一层靠三道防线（服务器纪律、内容闸门、文本写法），全部写在
[`docs/06-合规改写与内容边界.md`](06-合规改写与内容边界.md) 里。这里只强调一句：

> 私人服务器最大的合规风险不是服务器被扫描到，是**一张截图被发出去**。
> 所以内容闸门默认全关，即使只有一个人玩。

## 六、素材：六个容易踩的坑

| 素材 | 坑 | 规矩 |
|---|---|---|
| 游戏贴图/音效/语言文件 | 从客户端 jar 里提取出来用 | **绝不**。原版资源只能由游戏本身体提供，不能进仓库、不能改包分发 |
| 音乐 | 音游用现成曲子；BGM 用"网上找的史诗音乐" | 只用原版音效或**自己做的**。音游曲目必须原创或有书面授权——这是全项目最容易被追责的一处 |
| 皮肤 | NPC 用网图、玩家皮肤、真人照片 | 自己画。mmSupernaturals 的测试场已经示范了"运行时画两块颜色"的做法 |
| 建筑 | 下载别人的 `.schem`、付费地图包 | 自己盖。建筑外观著作权真实存在，"改了 30%"不是抗辩 |
| 字体 | 用 Minecraft 的字体文件做 UI | 不用。界面文字用系统字体渲染（Dialog 的正文就是普通文本，天然合规） |
| 现实地标 | 把圣母院/某教堂 1:1 搬进来 | 参照风格，不复刻具体建筑 |

## 七、开源许可证：矩阵与边界

| 组件 | 许可证 | 我们怎么用 | 义务 |
|---|---|---|---|
| Paper | GPL-3.0 | 只下载、不修改、不分发 | 不分发即无义务；若分发必须提供源码 |
| mmSupernaturals | GPL-3.0 | 运行期插件，反射只读 | 同上；若修改并分发，需公开修改 |
| Citizens | OSL-3.0 | 可选，运行期插件 | 不修改即无义务；OSL 有"外部部署"条款，改了要提供源码 |
| WorldEdit / WorldGuard | GPL-3.0（仓库未用标准 SPDX 标注，以 LICENSE 文本为准） | 构建期与运行期工具 | 同上 |
| LuckPerms | MIT | 可选 | 保留版权声明 |
| 本项目代码 | **GPL-3.0** | — | 与 mmSupernaturals 一致，便于互借代码 |

### 为什么本项目也选 GPL-3.0

因为两个仓库属于同一个人，而**代码迟早会互借**。许可证不一致会让"借一段"变成"不能借"，
最后逼出"抄一遍再改改变量名"这种既费时又不体面的事。选同一个，是最省事的合规。

### 一句必须说清楚的话

"把 GPL 插件放进 `plugins/` 跑，会不会传染我的服务器代码？"
通行的理解是**不会**——插件之间通过 Bukkit 的接口交互，不是链接成一个程序。
但这是一个有争议的边界，所以本项目的保守做法是：

- **不在仓库里放任何第三方 jar**（`.gitignore` + `plugins.tsv` 无校验和就不下载）；
- **不修改第三方插件的代码**，需要改行为的，走包装层或上游 PR；
- **要修改时，先问一句"改完能不能公开"**——能，就改；不能，就换方案。

这三条比任何法律意见都更容易执行。

## 八、数据与隐私

| 项 | 做法 |
|---|---|
| 收集什么 | 只收集游戏内数据（UUID、剧情旗标、在线时长）。不收集真实身份、联系方式、位置 |
| 皮肤签名服务 | 若启用第三方签名（SkinRestorer 一类），玩家的皮肤 URL 会出境到第三方——必须在隐私说明里写明，并允许关闭 |
| 遥测 | Paper 自带 bStats（匿名统计），可在 `plugins/bStats/config.yml` 关掉。要关就关，别让它成为"没告诉玩家的事" |
| 日志 | 保留 30 天，超期删除；不把日志用于任何分析以外的用途 |
| 删除权 | 提供"删除我的数据"通道（删玩家数据文件 + 剧情状态） |

## 十、免责声明模板

放在启动页、README、任何宣传材料的第一屏，一字不改：

> 这不是一个官方 Minecraft 产品。未经 Mojang、Microsoft 或网易（中国大陆的 Minecraft 独家运营方）
> 批准或关联。
>
> Not an official Minecraft product. Not approved by or associated with Mojang, Microsoft, or NetEase.

这句话不是客套。它是"民间项目"与"冒充官方"之间唯一一条看得见的界线，也是这个生态里
所有长期活下来的项目都在用的同一句话。
