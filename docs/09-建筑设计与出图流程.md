# 09 · 建筑怎么做：从查料到出图

这份文档是流程本身，不是某一栋房子的说明。每设计一座建筑都走一遍，顺序不能反。

## 一、四步

1. **查资料**：现实建筑（形制、构造、材料）、动漫场景（光线与镜头怎么读空间）、
   游戏场景（玩家怎么认路、怎么使用）。三样各取一条能落地的结论。
2. **提炼灵感**：写清楚"抄什么、不抄什么"。抄形制与动线，不抄装饰纹样；
   能落地的写进行为，落不了地的写进注释。
3. **结合游玩体验定设计**：先问玩家从哪来、进门第一眼看见什么、在里面做什么，
   再定平面与体量。**顺序反了就会得到一座好看但走不进去的房子。**
4. **建造 + 断言 + 出图**：门要能推开、楼梯要能上、路线要能走，全部写成测试；
   然后按五机位出图。

## 二、出图口径（五机位标准套）

等轴渲染器只有一个固定视角（从东南往下看）。要看其余三面，就把场景转过来：

| 序号 | 机位 | 做法 |
|---|---|---|
| 1 | 东南 | `rotated(0)` |
| 2 | 西南 | `rotated(1)` |
| 3 | 西北 | `rotated(2)` |
| 4 | 东北 | `rotated(3)` |
| 5 | 局部特写 | 通常是主入口立面，机械位按建筑特点挑 |

命令：

```
mvn -q -pl vespera-core -am test -Dtest=Shots -Dshots=inn -DfailIfNoTests=false
```

图落在 `docs/切图/<建筑>-<序号><方位>.png`。**图是渲染出来的，不是画出来的**——
方块与服务器里那 440 万个方块是同一份。

调试用的剖面（切掉某个高度看内部）：`-Dshots=inn,inndebug`。

## 三、客栈（车马店）这一栋：查料 → 设计

| 来源 | 结论 | 落成了什么 |
|---|---|---|
| 现实：英国 coaching inn | 形制是"临街主楼 + 穿堂拱门 + 内院 + 二层回廊 + 后院马厩"，回廊就是楼上客房的走廊 | 东立面开**两道口**：人行正门（带门套与门廊）、三格宽车马拱门；院子北、东两面做回廊，回廊有梯子从院里上去，尽头的门接二层走廊 |
| 现实：大堂与私厅分开 | 有钱的客人不进大堂，去 private parlour | 拱门南侧单独一间私厅：小桌、两支蜡烛、壁炉 |
| 动漫（芙莉莲 / 无职转生） | 室内低、暗、暖；白天也靠窗，烛火与炉火是唯一亮源；小空间用广角 | 层高五格（不贪高）；沿中轴挂四盏灯；拱门里也点了两盏，穿堂不是黑洞；窗小而多，不落地 |
| 游戏（Skyrim 烛炉厅 / 巫师 3 酒馆） | 进门必须一眼读出"柜台在哪、桌在哪、楼梯在哪" | 正门落在中段；柜台在右手贴北墙、退一格留出掌柜站位；楼梯在左手贴西墙；长桌走中轴 |
| 游戏（续） | 酒馆靠"门口那一团"被认出来，不是靠体量 | 三级石台 + 两根柱子 + 一片雨棚 + 两盏挂灯 + 挑出去的招牌 |

## 四、踩过的坑（都写成了注释或断言）

- **屋顶按"进深一半"起坡**：四十三格进深就是二十三米高的一个尖，整栋楼成了一口倒扣的锅。
  改用 `hipRoof` 显式给坡高（这里七格）。
- **隔墙砌到屋檐**：二层的隔墙一路穿到三层，把阁楼切成走不进去的窄缝——图上完全看不出来。
  隔墙只砌到 `f3 − 1`。
- **拿栅栏当凳子**：栅栏在体素里是整块，一条长凳就是一堵墙。凳子改用楼梯块，能迈上去。
- **回廊只有一格深**：栏杆和走道同格，人站不进去，整条廊一步都迈不动。廊要两格深。
- **柜台贴墙**：贴着墙就没有"掌柜站的那一边"。退一格。
- **墙外是邻居还开门**：南院墙本来留了一道"给货走"的小门，门外正对隔壁的墙。封掉。
- **家具摆在站人那一格**：床、桌、桶占了 y = 楼层标高，那一格就站不上人。测试要挑走道点位验。
