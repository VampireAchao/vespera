01风格参考

六张图分别对应：全城气象、圣座、王庭、角斗场、街市、城墙。它们回答的是"这座城看起来应该是什么样"，不是"它现在建成什么样"。

02三套布局

三套方案都满足你的硬条件：中心有阶梯金字塔圣座、正北有王座大厅、城内有角斗场、城墙可巡逻。差别在于它们怎么摆——这决定了你每天在城里走路的感觉。

方案 A · 圣座居中现结构

  • 气质：神权在正中，一切绕它转。
  • 好：从四个城门进来都先看见金字塔，辨识度最高。
  • 难：南北大道被塔截断，进城必须绕环；王座厅离得远。

方案 B · 双核南北

  • 气质：神权与王权正面相对，中间是一条仪式大道。
  • 好：南北大门能直着走到顶；广场在东侧，商业最旺。
  • 难：圣座不在正中，从东门进来第一眼看不到它。

方案 C · 三层山城

  • 气质：山城。仰视与俯瞰同时存在，最像"有历史"的城。
  • 好：层次最多，街景最好看；每个高度看城都不一样。
  • 难：工程量最大，挡土墙与台阶要单独做；平地不好找。

需要你拍板的三件事：

① 布局选 A / B / C（或"A 的圣座 + B 的仪式大道"这种混合，也行）。
② 风格参考里哪几张最接近你想要的？哪几张不对味，我换方向重出。
③ 城内密度：现在这种"街街贴房"的密度，是要更密（像威尼斯），还是留出更多院子与空地（像北方小城）？
